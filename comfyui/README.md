# 使用说明

把 `run_nvidia_gpu_api.bat`（放在和原来 `run_nvidia_gpu.bat` 同目录）：

ComfyUI 本身一直带 API（默认端口 8188），只是默认只监听 `127.0.0.1`。加上 `--listen 0.0.0.0` 就能允许局域网/远程调用。

### 关键改动说明

| 参数 | 作用 |
|------|------|
| `--listen 0.0.0.0` | 监听所有网卡，允许远程/局域网访问 |
| `--port 8188` | 明确指定端口（可选，默认就是 8188） |

### 安全提醒

- **默认没有任何鉴权**，局域网内任何人都能调用。
- 如果要暴露到公网，强烈建议：
  - 用 Cloudflare Tunnel / frp / Nginx 反向代理 + 鉴权
  - 或只开放给特定 IP

启动后访问 `http://你的IP:8188/system_stats` 能返回 JSON 就说明 API 正常。
